This is a R-based analysis done to analyze the CWR species observations in three protected areas in Finland, Norway and Sweden.
The observation data used in this project are downloaded to Zenodo: https://doi.org/10.5281/zenodo.24302177.

Packages needed: "tidyverse", "sf", "data.table", "here", "raster", "ggspatial", "writexl", "prettymapr"
Running the code:
git clone https://github.com/almanevala/CWR.git
cd CWR
